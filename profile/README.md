## Products and open source

We build and maintain our own products:

- [Metis](https://nacodestudios.it/en/project/metis), a software effort estimation engine that returns a median estimate and a calibrated 90% confidence interval
- [TrueUp](https://nacodestudios.it/en/project/trueup), a GitHub App that reports what a pull request makes possible and what it reimplements

We also co-founded [SpaceClub](https://spaceclub.it) and lead its development. It is a nightlife platform for guests, promoters and venues: events, digital tickets, table booking and QR entry in one app. What we did is in the [case study](https://nacodestudios.it/en/project/spaceclub).

The libraries are open source and Apache-2.0 licensed:

- [Kdrant](https://github.com/NaCode-Studios/Kdrant), a Kotlin client for the Qdrant vector database
- [Kmemo](https://github.com/NaCode-Studios/Kmemo), a semantic cache for LLM calls
- [Fluttorch](https://github.com/NaCode-Studios/Fluttorch), a toolchain from PyTorch to Flutter
- [Flutwire](https://github.com/NaCode-Studios/Flutwire), a network inspector for Flutter

[metis-benchmark](https://github.com/NaCode-Studios/metis-benchmark), a pre-registered blind test of software effort estimation on nine open datasets, is MIT licensed. If these save you time, you can [sponsor the work](https://github.com/sponsors/NaCode-Studios).
